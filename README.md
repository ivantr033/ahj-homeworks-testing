# Credit Card Validator (E2E & Unit Testing)

[![Card Validator CI](https://github.com/ivantr033/ahj-homeworks-testing/actions/workflows/webpack.yml/badge.svg)](https://github.com/ivantr033/ahj-homeworks-testing/actions/workflows/webpack.yml)

🔗 **Demo en vivo:** [https://ivantr033.github.io/ahj-homeworks-testing/](https://ivantr033.github.io/ahj-homeworks-testing/)

Widget interactivo para la validación de números de tarjetas de crédito mediante el **algoritmo de Luhn** y la identificación visual del sistema de pago (Visa, Mastercard, Mir, etc.). Este proyecto incluye una suite completa de pruebas unitarias (**Jest**) y pruebas de extremo a extremo (**Puppeteer**).

---

## 🛠️ Tecnologías utilizadas

* **JavaScript (ES6+)**
* **Webpack 4** + **Babel**
* **CSS3** & **HTML5**
* **Jest** (Testing unitario)
* **Puppeteer** (Pruebas E2E de automatización del navegador)
* **ESLint** (Reglas de estilo Airbnb)
